# Instruksi Codex

## Tujuan

Bangun aplikasi Flutter bernama Jadwal Kuliah untuk Android dengan pendekatan offline-first.

## Aturan kerja

- Kerjakan satu fitur per branch `feature/*`.
- Jangan menambahkan backend atau login sebelum MVP lokal selesai.
- Jalankan `dart format`, `flutter analyze`, dan `flutter test` sebelum commit.
- Tambahkan atau perbarui test untuk setiap perubahan perilaku.
- Pisahkan UI, model, penyimpanan data, dan logika jadwal.
- Gunakan bahasa Indonesia pada teks antarmuka pengguna.
- Jangan menyimpan secret, keystore, token, atau kredensial di repository.

## Definisi selesai

- Kode terformat.
- Tidak ada error analyzer.
- Semua test lulus.
- Perubahan dijelaskan di Pull Request.
