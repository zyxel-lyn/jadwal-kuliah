# Jadwal Kuliah

Aplikasi mobile Flutter untuk mengelola jadwal kuliah W, Ima, dan jadwal keberangkatan bersama.

## Target MVP

- Jadwal harian dan mingguan
- Jadwal W dan Ima
- Deteksi jadwal dengan hari dan jam yang sama
- Tambah, ubah, dan hapus jadwal
- Penyimpanan lokal
- Pengingat sebelum kuliah

## Menjalankan proyek

1. Pasang Flutter SDK versi stabil.
2. Jalankan `flutter create . --platforms=android` satu kali untuk menghasilkan folder platform.
3. Jalankan `flutter pub get`.
4. Jalankan `flutter test` dan `flutter run`.

## Alur Git

- `main`: versi stabil
- `develop`: integrasi fitur
- `feature/*`: satu branch untuk satu fitur
